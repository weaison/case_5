# Дневник путешествий

Учебный проект — веб-приложение «Дневник путешествий».
Работает без сервера на HTML, CSS и JavaScript. Данные хранятся в localStorage.

## Возможности

- Регистрация и вход пользователя
- Создание записи о своём путешествии
- Редактирование и удаление своих записей
- Просмотр путешествий других пользователей
- Поиск по названию и месту

### Дополнительные функции (3 из списка)
1. **Местоположение с привязкой к геопозиции** — кнопка «Моё местоположение» запрашивает координаты через Geolocation API. На странице записи координаты показаны на встроенной карте OpenStreetMap.
2. **Изображения мест** — в форму можно добавлять несколько ссылок на изображения. Они отображаются в галерее и в виде обложки карточки.
3. **Стоимость путешествия** — указывается сумма, отображается в карточке и в профиле пользователя (с подсчётом общей суммы).

localStorage под ключом `travel_db`.
Сброс: DevTools → Application → Local Storage → удалить `travel_db` → перезагрузить.
